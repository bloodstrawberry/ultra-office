# Ultra Office (울트라 오피스)

Ultra Office는 업무 생산성을 극대화하기 위한 올인원 웹 오피스 유틸리티 플랫폼입니다.

- **디자인 & 레이아웃 가이드**: [DESIGN_GUIDE.md](./DESIGN_GUIDE.md) 참조

---

## 주요 기능

- **텍스트 도구**: 정규식 스튜디오 (120+종 프리셋), 구조 데이터 변환 (JSON·CSV·XML·YAML), 텍스트 가공 & 보안/인코딩, 텍스트 Diff 비교, 이미지 텍스트 추출 (OCR)
- **데이터 비교**: 소스 코드/텍스트 정밀 Diff, 목록 라인 교집합/차집합 분석
- **파일 변환**: PDF 병합/분할/이미지 변환, 엑셀 ⇄ CSV·JSON, 이미지 포맷 일괄 변환
- **스프레드시트 / SQL 연습실 / 개발자 도구**: FortuneSheet 기반 시트, SQL 쿼리 실습, 실시간 코드 러너 등
